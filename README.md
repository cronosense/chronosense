# Chronosense.ai — GitHub Pages website

Static, responsive, multilingual concept website. No build step or framework required.

## Files
- `index.html` — page structure and metadata
- `styles.css` — responsive visual design
- `script.js` — language selector, mobile navigation and email hand-off
- `assets/smart-safety-band-concept.png` — illustrative concept image

## Publish on GitHub Pages
1. Create or open the repository that will host the website.
2. Back up the current site before replacing anything.
3. Upload the contents of this folder to the repository root (not the folder itself).
4. In GitHub, open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
6. Wait for the Pages deployment and open the URL shown in Settings → Pages.

## Important before publishing
- The contact form uses `mailto:contact@chronosense.ai`. Confirm that this mailbox exists and is monitored. If it does not, replace that address in `script.js` with a real contact address. This form does not transmit or store submissions on a server.
- The safety-band image is illustrative. It must not be presented as a working or certified device.
- The website deliberately describes Chronosense and N.O.A. as concepts. No clinical validation, medical function, security certification, partnership or working hardware is claimed.
- Add a real privacy notice and legal/company details if you later collect personal data, add analytics, or operate a backend form.
- Test the site on mobile and desktop after deployment.

## Local preview
Open `index.html` in a browser. For a more representative local test, use a simple local static server or GitHub Pages preview.
